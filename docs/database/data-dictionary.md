# Data Dictionary

## Conventions

- IDs are UUID strings generated by Prisma.
- Timestamp fields use UTC.
- `createdAt` and `updatedAt` exist on all mutable entities.
- Enums are stored as PostgreSQL enum types.
- Soft deletion is not used for published content; use `status = ARCHIVED` and version history.

## Core entities

### User

| Field | Meaning |
|---|---|
| `id` | Internal immutable identifier |
| `email` | Unique login identifier; nullable for future provider-only accounts |
| `emailVerifiedAt` | Verification timestamp |
| `passwordHash` | bcrypt hash; never exposed by APIs |
| `displayName` | Public-facing name |
| `locale` | Preferred UI locale |
| `status` | `ACTIVE`, `SUSPENDED`, or `DELETED` |

### Role and Permission

| Field | Meaning |
|---|---|
| `name` | Stable machine name such as `research_reviewer` |
| `description` | Human-readable purpose |
| `scope` | `GLOBAL`, `MODULE`, or `CONTENT` scope |
| `key` | Permission key such as `religious:review` |

### ContentItem

| Field | Meaning |
|---|---|
| `slug` | Stable public URL key |
| `type` | Content type such as `AYAH`, `HADITH`, `DUA`, `PROPHET_STORY` |
| `status` | Publishing state |
| `sourceId` | Primary canonical source reference |
| `licenseId` | Usage license record |
| `isDemo` | Marks demonstration-only records |
| `publishedAt` | Set only after publication |
| `searchVector` | PostgreSQL tsvector for full-text search |
| `trigramIndex` | Normalized string for fuzzy matching |

### ContentVersion

| Field | Meaning |
|---|---|
| `versionNumber` | Immutable monotonic version |
| `snapshotJson` | Complete content snapshot |
| `createdById` | Editor who created the version |
| `approvedById` | Reviewer who approved the version |

### Source

| Field | Meaning |
|---|---|
| `name`, `author`, `publisher`, `edition` | Citation identity |
| `licenseId` | Linked license |
| `verificationStatus` | `UNVERIFIED`, `PENDING`, `VERIFIED`, `REJECTED` |
| `sourceUrl` | Documentation or official reference |

### GradingRecord

| Field | Meaning |
|---|---|
| `grade` | Grading label from the source |
| `graderName` | Named grader or grading institution |
| `gradingSourceId` | Source containing the grading |
| `edition` | Edition used for grading |
| `verificationStatus` | Editorial verification state |

### ReviewAssignment

| Field | Meaning |
|---|---|
| `reviewerId` | Assigned user |
| `contentItemId` | Content under review |
| `decision` | `PENDING`, `APPROVED`, `CHANGES_REQUESTED`, `REJECTED` |
| `isTranslator` | Whether reviewer also produced the translation |

### CorrectionReport

| Field | Meaning |
|---|---|
| `reporterId` | Optional registered reporter |
| `contentItemId` | Reported content |
| `status` | `NEW`, `TRIAGED`, `RESOLVED`, `REJECTED` |
| `resolutionNotes` | Required before resolution |

### Donation

| Field | Meaning |
|---|---|
| `amountCents` | Integer minor units |
| `currency` | ISO currency code |
| `provider` | Payment provider key |
| `providerReference` | Provider transaction identifier |
| `status` | `PENDING`, `SUCCEEDED`, `FAILED`, `REFUNDED` |

No card number, CVV, or raw bank detail is stored.

## Audit fields

All audit records store actor, action, target type, target ID, before/after JSON, reason, IP hash, and timestamp. IP addresses are hashed rather than stored in plain text.
